# Exploring-the-Independent-Impacts-of-Stigmatised-Deprivation-on-Loneliness
About the Project: This repository holds code for the paper Exploring the Independent Impacts of Stigmatised Deprivation on Loneliness. Through the application of a hierarchical machine learning modelling approach on comprehensive survey data (n=2886) encapsulating features including loneliness, health and economic deprivation, this work evaluates the relationship between stigmatised deprivation and loneliness and its significant impact.
